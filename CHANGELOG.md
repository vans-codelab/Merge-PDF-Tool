# Changelog

## v1.0.0 - Initial Release

### Added
* Initial release of Merge PDF Tool
* Graphical user interface (GUI) built with Tkinter
* Support for selecting and merging multiple PDF files
* Drag and drop functionality for adding files
* Ability to reorder files before merging
* Option to remove individual files or clear the entire list
* Ability to choose the folder where the merged PDF will be saved
* Option to rename the merged PDF file
* User-friendly error messages for common input and validation issues

### Notes
* First public version of the application
